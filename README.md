---

## 🏗️ Architecture du Monorepo

Ce dépôt suit une structure de monorepo organisée pour une clarté maximale et une maintenance facilitée :

*   **[`/apps/vibenexus`](./apps/vibenexus)** : L'application web principale développée avec Next.js 15.
*   **[`/docs`](./docs)** : Documentation technique détaillée, guides d'architecture et vision produit.
*   **[`/infrastructure`](./infrastructure)** : Schémas de base de données SQL et configurations cloud.
*   **[`/scripts`](./scripts)** : Outils d'automatisation, de maintenance et de déploiement.

---

## 🎯 Vision Architecturale

VibeNexus repose sur trois piliers fondamentaux que je souhaite mettre en avant pour les recruteurs :

1.  **Dette Technique sous Contrôle** : Un système intégré de score de vitalité et d'obsolescence pour chaque projet.
2.  **Intelligence Contextuelle** : Utilisation de l'IA pour générer des résumés hebdomadaires, des ADR (Architecture Decision Records) et des recommandations stratégiques.
3.  **UI/UX Premium** : Une interface fluide, réactive, et entièrement localisée, pensée pour l'utilisateur final.
